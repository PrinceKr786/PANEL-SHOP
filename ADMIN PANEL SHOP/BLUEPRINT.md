## Architecture

### Authentication Flow
1. `pages/index/index.html` → `pages/index/index.js` handles login via `signInWithEmailAndPassword`
2. Every admin page runs `assertAdmin()` from `auth-guard.js` on DOMContentLoaded
3. `auth-guard.js` checks for `ADMIN_UID` (centralized in `firebase.js`), redirects to `pages/index/index.html` if unauthorized
4. `auth-guard.js` also provides `logAudit()` for all admin actions

### Sidebar
- `pages/*/index.html`... `pages/*/<name>.html` contain `<div id="sidebarContainer">` + `<script type="module">` importing `sidebar-loader.js`
- `sidebar-loader.js` fetches `components/shell/sidebar.html` and injects it
- `sidebar.html` has inline CSS (cyberpunk theme) + dynamic imports for `firebase.js` and `badges.js`
- All nav links are relative per page folder (`../dashboard/dashboard.html`, `../users/users.html`, etc.)
